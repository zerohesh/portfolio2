# ZeRo Graphics Portfolio

A premium dark portfolio site for Sachintha Heshan. Built with React, Vite, GSAP, Lucide icons and optional Supabase persistence.

- Public portfolio: `npm run dev`
- Admin route: `/admin`
- Configuration guide: `SETUP.md`
- Supabase schema and security policies: `supabase/schema.sql`

See `SETUP.md` before deploying or enabling admin access.
